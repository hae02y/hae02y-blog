함수와 변수 이름을 고민하는 시간이 아깝지 않다는 걸 다시 느꼈다. 처음엔 "동작만 하면 되지"라고 생각했는데, 몇 달 뒤 내 코드를 다시 열었을 때 가장 먼저 발목을 잡은 건 애매한 이름들이었다.

## 기억에 남은 문장

작은 함수로 쪼개는 것에 대한 부분이 특히 와닿았다. 하나의 함수가 하나의 일만 하도록 두면, 테스트도 쉬워지고 나중에 고칠 때도 두렵지 않다.

## 적용해 본 것

- 변수명에 의도를 담기
- 주석 대신 코드로 설명하기
- 함수는 한 가지 일만

다 읽고 나서 완벽한 코드를 쓰게 된 건 아니지만, "이 이름이 최선일까?"를 한 번 더 묻는 습관이 생겼다.
